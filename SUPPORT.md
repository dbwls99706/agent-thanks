# Support

## Questions and usage help

Search existing GitHub Issues before opening a new one. If the question has not
been answered, open an issue with:

- `agent-thanks --version` output
- Operating system and Python version
- The command that was run
- Sanitized output or a minimal reproduction

Never include GitHub tokens, private repository contents, or unredacted session
logs.

## Bugs

Use the bug report form and include the smallest reproducible example possible.
Security vulnerabilities must follow [SECURITY.md](SECURITY.md) instead of the
public issue tracker.
